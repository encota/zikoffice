# Translations

The interface is available in **English, Italian, Spanish, French, German and Portuguese**. At the first start it follows
the system language (English if the system language is not one of these); change it in *File → Preferences → Interface language*.

> The translations were written by the maintainer with an AI assistant and **have not been reviewed by native speakers**.
> Fixes are among the most useful contributions. You do not need to program: you only edit a table.

## How it works

The Italian text in the code is the **key** (`t("Incolla")`, `h("button", {}, "Incolla")`). The translations are rows in
`app/src/i18n/tables/`:

```ts
["Incolla", "Paste", "Pegar", "Coller", "Einfügen", "Colar"],   // [it, en, es, fr, de, pt]
```

Phrases with values use `{0}`, `{1}` (`"Salvato: {0}"`); the placeholders must be identical in every language.
Text produced by the Rust side also goes through the same tables (they are matched as patterns).

- `ui.ts` — ribbon, menus, dialogs, messages; `content.ts` — templates, tooltips, single words, Rust messages;
  `functions.ts` — spreadsheet function descriptions and argument names; `slides.ts` — presentations.
- Keyboard shortcuts are converted per language (`Ctrl+Maiusc+S` → `Ctrl+Shift+S`, `Strg+Umschalt+S`).
- **Spreadsheet**: the language also changes function names (`SUM` / `SOMMA` / `SUMA` / `SOMME` / `SUMME`), the argument
  separator, the decimal mark and the name of new sheets. Files always store the English form, so a file written in one
  language opens in the others. Portuguese uses English function names (the engine has no Portuguese ones yet).
- **Documents**: dates, numbers and the text language follow the chosen language; templates are translated; the spell checker uses the Hunspell dictionary of that language, if installed.

## Fix a translation

1. Find the row in `app/src/i18n/tables/*.ts` (search for the Italian or the English text).
2. Edit the cell of your language. Keep `{0}`-style placeholders and the quotes.
3. `cd app && npm test` — `tests/i18n.test.ts` checks that every row is complete and placeholders match.
4. Open a pull request. If you are not comfortable with git, open an issue with the corrected text.

## Add a phrase

Write the Italian text in the code through `t()` / `h()` / `toast()` (or as a ribbon label), then add a row with all six
languages. `npm run i18n` lists Italian strings in the code that have no row (technical names and the assistant's prompts are
expected false positives).

## Add a language

Add a column to every row of the tables, an entry to `LANGS` in `app/src/i18n/index.ts` (tag, spell-checker dictionary,
spreadsheet function language and locale, key names), and the language to the spell-checker list in the preferences.
IronCalc supports formula languages en, es, fr, de, it; for others function names stay English.
Right-to-left and CJK languages need layout and font work in the document editor: please open an issue first.

## Not translated

The prompts sent to the assistant (kept in Italian), and the descriptions of file types in the system's file-association dialogs.
