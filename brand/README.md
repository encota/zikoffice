# Brand assets

The logo was created with an AI image generator (Google Gemini) by the maintainer. Copyright protection of AI-generated
artwork is uncertain in many countries, so the name and logo are protected by the usage rule below rather than by copyright alone.

| File | What it is |
|---|---|
| `zikoffice_logo.jpeg` | Original logo (square, with text) |
| `zikoffice-icon.png` | Full logo, 1024 px, transparent corners — used for the large application icons |
| `zikoffice-mark.png` | The "Z" alone on a dark background — used for small icons (16–71 px), the window corner and the favicon |
| `zikoffice-mark-256.png` | The "Z" alone, 256 px — used by the example presentation |

**Use of the name and logo.** The source code is licensed under MIT OR Apache-2.0 (see the top-level `LICENSE-*` files).
The **ZikOffice name and the images in this folder are not part of that license.**

- You are welcome to use them to **refer to this project**: articles, links, talks, and packages of the unmodified program.
- **Forks made to contribute** (a copy on GitHub to send a pull request) can of course keep the name and logo.
- If you publish a **modified version as your own program**, please give it a different name and logo, so that people can tell
  it apart from ZikOffice and are not misled about who made it or who supports it. The code itself you are free to reuse under the license.
